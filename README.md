# Power BI Analyst - DIO

Projeto desenvolvido como parte do desafio de Power BI da DIO, utilizando o dataset Financial Sample para construção de análises de vendas, lucro, países e segmentos.

## Objetivo

Desenvolver um relatório interativo no Power BI, reproduzindo as análises apresentadas durante o curso e criando uma página adicional conforme os requisitos do desafio.

## Estrutura do relatório

### Página 1 — Relatório de Vendas

A primeira página apresenta uma visão geral dos principais indicadores de vendas:

- Total de Vendas
- Total de Descontos
- Custo dos Produtos Vendidos
- Unidades Vendidas
- Vendas por Mês
- Vendas por Segmento
- Vendas por Produto
- Vendas e Unidades Vendidas por País

### Página 2 — Relatório de Lucro Detalhado

A segunda página apresenta análises relacionadas ao lucro:

- Lucro por Ano
- Lucro por País
- Lucro por Segmento
- Lucro por Trimestre

### Página 3 — Análise por País e Segmento

A terceira página foi desenvolvida conforme os requisitos específicos do desafio, contendo:

- Mapa com Soma de Sales e Unidades Vendidas por País
- Mapa com Soma de Profit por País
- Gráfico de pizza com Lucro por Segmento

## Ferramentas utilizadas

- Microsoft Power BI Desktop
- Dataset Financial Sample
- GitHub

## Dataset

O projeto utiliza o dataset Financial Sample disponibilizado no repositório oficial do desafio:

https://github.com/julianazanelatto/power_bi_analyst

## Arquivo do projeto

O arquivo `.pbix` contém o relatório completo desenvolvido no Power BI, incluindo as três páginas de análise e seus respectivos visuais.
